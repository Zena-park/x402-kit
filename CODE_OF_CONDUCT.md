# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, assume good faith, and keep discussions focused on the
work. Harassment, personal attacks, and discriminatory language are not
tolerated in issues, pull requests, or any other project space.

To report a problem, open a private vulnerability-style report through
GitHub's "Report content" tooling or contact the maintainer through their
GitHub profile. Reports are handled confidentially.
